# Apex 灵敏度实验台

**一个单文件、纯前端的 Apex Legends 腰射灵敏度测量工具。**
用对照实验 + 统计判定回答一个问题：在你手里，A 和 B 两个灵敏度到底哪个更稳——还是根本分不出来。

> 无需安装：桌面版 Chrome / Edge 打开即用。不碰游戏、不读数据、无服务器、无追踪。
> 在线使用：https://R1kka-ovo.github.io/apex-sens-lab/
> 离线使用：下载 `index.html` 双击打开即可。

## 这是什么

把「该用什么灵敏度」从"玄学讨论"变成一次可复现的测量：

- **输入保真**：Pointer Lock + `unadjustedMovement`（绕过系统指针加速），1 个鼠标计数 = 0.022°，与游戏引擎换算一致（前提：游戏内 FOV 与本页设置一致）。
- **对照实验**：每回合是 A/B 两个灵敏度的对决，同难度、两套难度构成相同但轨迹不同的目标脚本（防止记住轨迹刷分），出场顺序随机并跨轮平衡。
- **ABBA 决胜**：决胜阶段每人各打两段、交替出场（位置均值 2.5），线性疲劳/练习漂移在配对差值中被数学抵消；残余漂移由固定脚本的「锚点」小测估计并补偿（±15 分上限）。
- **自适应难度 Lv.1–12**：分数过高（太简单）或过低（太难）都会失去区分度，难度自动升降，让测量始终停在敏感区。
- **统计判定**：差值必须超过噪声阈值（≥ 2×标准误，且不低于 2 分）才判胜负；分不出来就换任务加深，仍然分不出来就如实输出「这些值在实践中等价」及不可分辨区间。

## 它不是什么

- 不是训练器，不会直接提高枪法；
- 不测量开镜（ADS）与倍镜灵敏度；
- 结论是浏览器环境下的统计估计，建议按推荐值在游戏内实际玩 1–2 天再最终确认。

## 功能一览

- 六类瞄准任务：快速定位（±135°，累计 270° 拉枪覆盖）、目标切换（仅正前方）、微调点击、平滑跟枪、变速跟枪、快速变向跟枪；跟枪类约占一半。
- 智能推算贯穿全程：随数据累积持续重新拟合、提出新候选并实测；自动推算有次数上限，结果页可手动发起「正式挑战」。
- 科学控制：定时休息提醒、疲劳检测（自动停止深化）、漂移诊断图、不可分辨区间与 0.1 档 DPI 换算建议。
- 防干扰：测试期间屏蔽鼠标右键 / 中键 / 侧键；退出指针锁定自动暂停；Esc 随时暂停。
- 画面：FOV 70–120 自由输入（支持垂直换算），16:9 / 16:10 / 4:3，黑边 / 拉伸。
- 表现层：结果页图表逐个揭晓（可跳过、支持系统级"减少动态效果"）。

## 快速开始

1. 用桌面版 Chrome / Edge 打开网页（或双击本地 `index.html`）；
2. 关闭 Windows「提高指针精确度」：设置 → 鼠标 → 其他鼠标选项 → 指针选项；
3. 填写 DPI、游戏 FOV（与游戏内一致）、测试长度（快速 ≈ 8 分钟 / 标准 ≈ 15 分钟 / 完整 ≈ 18 分钟）；
4. 全屏 → 锁定鼠标 → 按提示完成测试（用平时最舒服的姿势，不要为了分数改变习惯）；
5. 查看结论：推荐值、eDPI、cm/360、不可分辨区间。

## 常见问题

**为什么本地打开时控制台有 file:// 相关提示？**
浏览器对本地文件的安全策略提示，与程序逻辑无关，不影响使用；部署到 https 环境（如 GitHub Pages）后不再出现。

**FOV 超过 110 怎么办？**
需要启动项 / autoexec 执行 cl_fovScale（社区做法，1.00=70 / 1.55=110 / 1.70=120 为社区近似值）。请先在游戏内确认生效；注意多数锦标赛规则禁止该做法。

**结果会不会有偏差？**
会。浏览器与游戏是两套输入/渲染管线，疲劳与练习效应无法被完全消除（只能被平衡与补偿）。程序会把这些不确定性明确展示出来——包括"测不出区别"这种诚实的结论。

**支持手柄 / 手机吗？**
不支持。仅桌面鼠标，且目前只测腰射。
