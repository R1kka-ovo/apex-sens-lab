① 基础设置

显示模式：该选「黑边」还是「拉伸填满」？（点开查看）

· 先给结论：绝大多数人保持默认的「黑边」。只有当你在游戏里故意把画面拉变形时（例如用 4:3 分辨率在 16:9 显示器上全屏拉伸），才选「拉伸填满」。
· 这两者到底差在哪：本页的打靶画面要按你选的分辨率比例来画。比例和屏幕不一致时——
　「黑边」＝保持比例，四周留黑边。圆形靶就是正圆，屏幕上的角度比例与你选的 FOV 一致。
　「拉伸填满」＝强行铺满整屏。画面被拉伸，圆形靶会变成椭圆，横向角度被放大。
· 30 秒自测该选哪个：进游戏，看远处的圆形物体（灯、桶、圆标）——
　① 是正圆、屏幕比例和显示器一致 → 选黑边；
　② 明显被拉宽成椭圆（画面变"扁"、水平方向被撑开）→ 选拉伸填满（这样本页的拉伸程度才和你游戏一致）；
　③ 游戏里是上下左右有黑边、画面保持比例 → 选黑边。
· 选错的后果：屏幕上的角度比例会和你游戏里看到的不一致，瞄准手感的参照就偏了——但不影响灵敏度结论本身：本页的鼠标计数→角度换算是 1 计数 = 0.022°，与显示模式、分辨率比例都无关；同一会话内所有候选值也都在同一设置下比较。也就是说，选错只会让你"照着打的手感"对不上，不会让推荐值算错。
· 不确定就选「黑边」：它是失真最小的选项，也是绝大多数玩家的情形。

FOV 说明：范围与「数值含义」怎么选（点开查看）

· 「数值含义」怎么选——只看你的数字从哪来：
　① 直接读自游戏内 FOV 滑块（70–110）→ 选「水平 · 4:3 基准」。Apex 的 FOV 按 4:3 基准的水平视野计算（社区实测确认）：同一数字在 16:9 屏幕上实际水平视野更大——滑块 110 换算到 16:9 屏幕约为：水平 124.6°、垂直 93.9°。
　② 数字来自攻略 / 换算工具，且标明是“16:9 水平” → 选「水平 · 16:9 基准」。
　③ 数字标明是“垂直” → 选「垂直」。
· 范围：水平 70–120、支持 0.1 小数；选「垂直」时自动切换为 42–105。超范围会被夹回边界，并在下方预览里提示实际生效值。
· 选错基准的后果：本页的画面缩放与视野范围会和游戏不一致（打靶观感与难度构成随之变化）；但灵敏度结论不受影响——同一会话内所有对比都在同一设置下进行，cm/360 换算也不受基准影响。
· 小字补充：社区实测认为滑块显示值与引擎真实值有最多约 1.5° 的出入（真实值 = cl_fovScale × 70，如滑块 110 对应真实 4:3 水平 ≈ 108.5°）。本页按你填写的数字直接计算，这点差异对测试没有实际影响。
· 110 以上需要用启动项 / autoexec 执行 cl_fovScale（社区近似：1.00=70 / 1.27=90 / 1.55=110 / 1.70=120，中间值按线性近似）。请先在游戏内确认已生效；社区反馈该做法普通对局可用，但多数锦标赛规则禁止。
· 游戏内 FOV 与本页设置不一致时，屏幕上的角度比例对不上——请务必先对齐再开始。

③ 高级选项

这些选项分别做什么？（点开查看）

· 自适应难度：每轮看实际得分——≥86 分难度 +2、≥78 +1、≤44 −1、≤34 −2（偏移 −2~+5）。避免“太简单→区分不出来”和“太难→同样区分不出来”。
· 瞄准数据建模（持续推算）：采集点击落点误差 / 失误距离 / 过冲 / 修正次数，每累积约 4 段新数据就重新拟合一次；搜索阶段模型候选会直接作为挑战者出场，决胜前后还会各安排一次实测对局。没有可测的新候选时不会产生额外对局（模型可能错，实测说了算）。
· 跟枪命中时枪声变亮：按住左键持续开火；未命中是较闷的枪声，命中时音色变亮并叠一击清脆提示。关闭后所有枪声相同。
· 离屏方向箭头：目标在你的视野之外（主要出现在快速定位的广角回合）时，屏幕边缘显示指向箭头。追求更“干净”的画面可以关掉。
· 漂移校准（锚点）：各阶段前后插入一小段固定任务测量你的状态，用于补偿学习/疲劳带来的分数漂移。
· 定时休息：按“有效瞄准时间”计时，到点强制建议休息，休息后自动重新校准。
· 自适应热身：先练到分数稳定再开始计分，把学习曲线最陡的一段排除在外。
· 新任务试打：每个任务第一次出现前先打一小段（不计分），抵消任务特异性学习效应。

测试范围与脚本独立性（拉枪范围 / 脚本不重复 / 跟枪靶 / 枪声）

· 拉枪范围：快速定位的目标可出现在当前朝向 ±135°（累计覆盖 270°），连续广角目标交替左右，屏幕边缘箭头指示方向。目标切换只在正前方：两靶都出现在当前朝向 ±约 50° 内（任何情况下不超过 90°），不需要大幅转身，考验的是准星在两个目标间的快速转移与精准落点。
· 脚本独立性：每次计分使用的目标脚本都不同——左右方向严格等量、距离按分位分层抽样后随机打乱；同一会话内不存在重复轨迹，不同会话之间也不同（随机盐）。因此无法靠“记住上一遍的靶位”刷分；A/B 两套脚本的难度构成一致，脚本难度差不会混入灵敏度比较。
· 唯一例外：状态校准“锚点”故意使用固定脚本——它是测量你状态变化的尺子，必须保持恒定条件；锚点不参与灵敏度比较。
· 跟枪靶：平滑跟枪（青色）/ 变速跟枪（红色）/ 快速变向跟枪（紫色）使用圆形移动靶，靶圈半径即真实命中判定半径；按住左键命中时靶圈会短暂高亮。变速跟枪与快速变向跟枪的难度已整体下调：靶圈分别约为同难度基准的 1.60 倍与 2.20 倍半径，同时移动速度更低、换向间隔更长、速度跟随更缓——这两项属于“稳定性/覆盖”性质的任务，不是精度任务。
· 跟枪权重：搜索与决胜阶段中跟枪类任务约占一半；「快速变向跟枪」安排在中高难度轮次。
· 枪声：跟枪按住左键持续开火（约 630 发/分）；未命中=较闷的枪声，命中=音色更亮并叠一击清脆提示；松开左键没有枪声也不计分。

难度分级说明（Lv.1–12 参数表与推进规则）
科学控制说明（抗疲劳 / 抗练习效应）

① 设计层：决胜用 ABBA 交替（位置均值 2.5），线性疲劳/学习漂移在配对差值中被数学抵消；搜索顺序随机并跨轮次平衡；每段使用不同脚本以消除“同一轨迹打多遍”的练习转移。
② 模型层：锚点估计状态漂移并补偿分数（上限 ±15 分）；休息后重建基线。假设：锚点测得的漂移曲线按同一比例外推到其他任务。
③ 规则层：定时强制休息；锚点明显下滑时判定疲劳，自动停止深化。
④ 边界：练习效应与疲劳只能被削弱与平衡，无法完全消除。最彻底的做法仍是分次测试（同一天内测两轮，或分两天各测一轮）。

① 用 Chrome / Edge 打开并允许全屏；
② Windows「提高指针精确度」已关闭（设置 → 鼠标 → 其他鼠标选项 → 指针选项）；
③ 游戏内 FOV / 显示比例与本页选择一致；
④ 操作：空格 推进回合，Esc 暂停，R 重开当前段（不计分，重开会更换脚本）；
⑤ 测试进行中鼠标的右键、中键与侧键已被屏蔽（防止浏览器菜单 / 前进后退等指令打断测试）；若不慎退出指针锁定，测试会自动暂停，可点击继续；
⑥ 跟枪任务请持续按住左键开火（松开期间不计分、也没有枪声）；
⑦ 目标切换任务请打高亮的那个靶，命中后另一个靶会变为高亮；
⑧ 屏幕边缘出现箭头时（主要出现在快速定位的广角回合）请转身把目标拉回屏幕内；
⑨ 出现姿势确认清单时请务必照做——本次测试是为了找出最适合平时的你的灵敏度，不要为分数改用不习惯的姿势。
